# Samy Amani

MSc student in Computer Science (integrated Master's–PhD track) at Sorbonne Paris Nord University.
I want to build agents that learn on their own, in any environment. Today that means deep reinforcement learning and LLM agents.

### What I'm working on

- **tft-rl** *(private for now)*: a high-fidelity reinforcement learning environment for *Teamfight Tactics*. It is the base for training an RL agent.
- **[PredicTFT](https://predictft.com)**: a model trained on simulated fights that predicts the outcome of any TFT fight in about a second, used by the TFT community (18 languages, 2D view or in-browser 3D view).
- **[UnrealEngine-WebGPU-5.7](https://github.com/justsamyyyy/UnrealEngine-WebGPU-5.7)**: Unreal Engine 5.7 games running in the browser with WebGPU, built on Windows. It powers the PredicTFT 3D view.
- **[MIKATA](https://github.com/justsamyyyy/MIKATA)**: a French-speaking voice agent that acts on a Windows PC with 60+ tools, and turns successful tasks into skills it replays without the LLM *(on hold)*.

### Research interests

Deep RL · open-ended learning · learned simulators and world models · agents that build their own tools
